# 7. No verdict

Date: 2026-11-14 · Status: accepted

**Decision.** A finding is one of four classes (disclosed, vague, not disclosed, contradicted), quotes the notice sentence or says none matched, and cites the rule it relates to. Nothing is scored pass or fail, and the rule set (`rules.yml`) says what a rule states, never whether the user meets it. The classes describe the notice against the data, not the data against the law.

**Why.** Joel's call of 2026-11-08: cite the rule, never a verdict. Whether a notice is enough is for the user and their counsel.

**Also.** Nothing is compared until the user confirms `policy.yml`. A low-confidence column proposal makes a provisional finding that isn't counted until confirmed. AI only drafts the policy; deterministic code decides every finding.
